# Бот новостей об ИИ

Следит за новыми моделями и сам публикует их в Telegram-канал: цена за 1M токенов,
контекст, модальности, оценка LMArena. В личке с ботом работает рейтинг топ-50
с кнопками.

**Стоимость: 0 ₽.** Telegram Bot API, OpenRouter, Hugging Face и GitHub Actions —
всё на бесплатных тарифах, без карт и пробных периодов.

```
🆕 Claude Fable 5.2
Anthropic · 09.11.2026

🧠 Ум: 1504 Elo · #5 в LMArena
💵 $8 вход / $40 выход за 1M
    кэш: $0.2 за 1M
📏 Контекст: 1M · ответ до 128K
👁 Вход: текст, фото, файлы
🧩 Reasoning: да · high/medium/low

🔗 Открыть на OpenRouter
#Anthropic #новый_ии
```

---

## Что понадобится

| Что | Зачем | Платно? |
|---|---|---|
| Telegram | канал и бот | нет |
| GitHub | расписание и хранение данных | нет |
| Cloudflare | мгновенные команды `/top` | нет |

Первые два обязательны. Cloudflare нужен только для интерактивных команд —
без него бот всё равно будет постить новости, но `/top` не заработает.

---

## Шаг 1. Создать бота

1. Открой [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Имя — любое («Новости ИИ»), username — любой свободный, заканчивается на `bot`.
3. BotFather пришлёт **токен** вида `8123456789:AAH...` — скопируй, он понадобится.

Меню команд и описание бот поставит сам при первом запуске.

---

## Шаг 2. Создать канал

1. Новый канал в Telegram (публичный или закрытый — не важно).
2. Настройки канала → **Администраторы** → добавить своего бота →
   включить право **«Публикация сообщений»**.
3. Запомни адрес канала: для публичного это `@my_channel`.

> Бот не может читать сообщения в канале — команды работают только в личке с ботом.
> Это ограничение Telegram, а не бота.

---

## Шаг 3. Положить проект на GitHub

1. Открой [github.com/new](https://github.com/new).
2. Имя: `ai-news-bot`. Тип: **Public** (так Actions бесплатны без лимита минут,
   а Cloudflare может читать файл с рейтингом без токена).
3. **Create repository**.
4. На странице репозитория: **Add file → Upload files**, перетащи туда
   всё содержимое папки `ai-news-bot` (сами файлы и папки `bot`, `worker`,
   `data`, `.github`), но не саму папку.
5. **Commit changes**.

Если у тебя установлен git, проще так:

```bash
git clone https://github.com/<твой-логин>/ai-news-bot.git
# скопировать файлы проекта в клон
git add . && git commit -m "init" && git push
```

> Если папка `.github` не загрузилась (бывает при перетаскивании на Windows),
> создай файл вручную: **Add file → Create new file**, в имени напиши
> `.github/workflows/watch.yml`, вставь содержимое одноимённого файла из проекта.

---

## Шаг 4. Секреты репозитория

Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из BotFather |
| `TELEGRAM_CHAT_ID` | `@my_channel` или числовой id канала |
| `AA_API_KEY` | ключ [Artificial Analysis](https://artificialanalysis.ai) — необязательно, добавляет второй рейтинг «ума» |

`AA_API_KEY` можно не добавлять: без него бот работает на одном LMArena,
а строки с AA Index в постах просто не будет.

Числовой id нужен для приватного канала без ссылки: временно напиши боту в личку
`/start`, открой `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди
`"chat":{"id":-100...}`. Для публичного канала достаточно `@username`.

---

## Шаг 5. Первый запуск

1. Вкладка **Actions** → слева **AI news bot** → **Run workflow** → **Run**.
2. Дождись зелёной галочки (около минуты).

Что произойдёт:

- соберётся `data/leaderboard.json` — рейтинг LMArena с ценами OpenRouter;
- бот запомнит все существующие на тот момент модели и **не будет** постить их пачкой;
- в канал придёт одно приветственное сообщение «Бот на связи».

Дальше бот работает сам: каждые 10 минут проверяет OpenRouter и публикует
только те модели, которых раньше не было.

---

## Шаг 6. Команды: Cloudflare Worker

1. [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** →
   **Create** → **Worker** → имя `ai-news-bot` → **Deploy**.
2. **Edit code** → удали заготовку → вставь содержимое `worker/worker.js` → **Deploy**.
3. **Settings → Variables and Secrets** — добавь четыре переменные:

| Имя | Значение |
|---|---|
| `BOT_TOKEN` | тот же токен BotFather (тип Secret) |
| `DATA_BASE` | `https://raw.githubusercontent.com/<логин>/ai-news-bot/main/data` |
| `WEBHOOK_SECRET` | любая случайная строка, например `wh-7f3a91` |
| `INSTALL_KEY` | другая случайная строка, например `install-2b8c44` |

4. Открой в браузере:
   `https://ai-news-bot.<твой-поддомен>.workers.dev/install?key=install-2b8c44`

Должно вернуться `{"ok":true,"result":true,"description":"Webhook was set"}`.
Значит Telegram теперь отправляет команды в воркер.

---

## Шаг 7. Проверка

Напиши боту в личку:

- `/start` — приветствие и кнопки;
- `/top` — топ-50, листается кнопками ⬅️ ➡️;
- `/top labs` — только топ-лаборатории;
- `/top 21` — сразу с 21-й позиции;
- `/model gemini` — карточка модели;
- `/new` — что вышло за 7 дней.

Если `/top` отвечает «Рейтинг пока пуст» — значит шаг 5 ещё не отработал.

## Что внутри

```
bot/
  main.py               поиск новых моделей и публикация
  build_leaderboard.py  сборка рейтинга LMArena + цены OpenRouter
  format.py             тексты постов
  match.py              сопоставление названий LMArena и OpenRouter
  telegram_setup.py     меню команд и описание бота
  keepalive.py          защита от отключения cron через 60 дней
  sources/
    openrouter.py       модели, цены, контекст, модальности
    lmarena.py          рейтинг: parquet → JSON-вьюер → прошлый снимок
worker/worker.js        команды /top /new /model /help
data/leaderboard.json   рейтинг (обновляется раз в сутки)
data/recent.json        свежие релизы для /new
state.json              какие модели уже видели
aliases.json            ручные пары «LMArena → OpenRouter»
```

Как это работает:

```
GitHub Actions (каждые 10 мин)            Cloudflare Worker (вебхук)
├─ OpenRouter → новые модели              ├─ /top /new /model /help
├─ фильтр топ-лабораторий → пост в канал  ├─ кнопки ⬅️ ➡️ и 🌍/🏢
└─ раз в сутки: data/leaderboard.json     └─ читает этот файл через CDN
```

### Два рейтинга «ума»

| Источник | Что даёт | Ключ | Цена |
|---|---|---|---|
| LMArena | Elo и место среди ~365 моделей | не нужен | 0 ₽ |
| Artificial Analysis | Intelligence Index и место в мире | бесплатный, 100 запросов/день | 0 ₽ |

AA обновляется раз в сутки — это 3–4 запроса из ста. Если ключа нет,
источник отключается сам, бот продолжает работать на LMArena.

## Настройки

| Что | Где |
|---|---|
| Список лабораторий | `bot/config.py` → `LABS` |
| Частота проверки | `.github/workflows/watch.yml` → `cron: "*/10 * * * *"` |
| Постов за один запуск | `bot/config.py` → `MAX_POSTS_PER_RUN` |
| Моделей на странице `/top` | `worker/worker.js` → `PAGE_SIZE` |
| Цены для моделей без пары | `aliases.json` |

### Добавить лабораторию

В `bot/config.py`:

```python
LABS = {
    ...
    "nousresearch": "Nous Research",
}
```

Ключ — префикс id в OpenRouter (`openrouter.ai/<префикс>/...`).
После изменения перезапусти workflow.

### Убрать задержку постов

Заменить `*/10` на `*/5` в `watch.yml`. Быстрее GitHub не даст: минимальный
интервал cron — 5 минут, и на пиках он всё равно опаздывает.

## Частые проблемы

**Бот молчит, в Actions красный крест.**
Открой лог. Чаще всего: не задан `TELEGRAM_CHAT_ID`, бот не админ канала,
или канал указан без `@`.

**`sendMessage: chat not found`.**
Неверный `TELEGRAM_CHAT_ID`. Для канала нужен `@username` (публичный)
или числовой `-100...` (приватный).

**`/top` отвечает «Данные временно недоступны».**
Воркер не смог прочитать `data/leaderboard.json`. Проверь `DATA_BASE` —
в конце не должно быть `/` и имя ветки должно совпадать (`main`).

**`/top` пустой, а посты идут.**
Рейтинг ещё не собран. Actions → **Run workflow** и подожди минуту.

**У части моделей «—» вместо цены.**
Такая модель есть в LMArena, но её нет в OpenRouter, либо названия не совпали.
Допиши пару в `aliases.json` и перезапусти workflow.

**GitHub пишет «This scheduled workflow is disabled».**
Так бывает после 60 дней без коммитов. Бот сам обновляет `.keepalive` раз в месяц,
а если всё же случилось — нажми **Enable workflow**.

**Вебхук отвечает 404.**
`WEBHOOK_SECRET` в Cloudflare не совпадает с тем, что был при вызове `/install`.
Поменяй переменную и вызови `/install` ещё раз.

## Локальный запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt

python -m bot.build_leaderboard
python -m bot.main --dry-run
```

`--dry-run` печатает посты в консоль и ничего не отправляет.
`--seed` запоминает текущие модели без публикации.

## Ограничения

- **Задержка 5–20 минут.** GitHub не гарантирует запуск ровно по расписанию.
  OpenRouter обычно индексирует модель через несколько минут после анонса.
- **Только то, что есть в OpenRouter.** Модель без публичного API бот не увидит.
- **LMArena обновляется примерно раз в сутки.** У свежей модели оценки может
  не быть: пост выйдет с пометкой «оценки пока нет», а бот допишет её позже,
  отредактировав сообщение.
- **Репозиторий публичный**, поэтому `state.json` и рейтинг видны всем.
  Секретов там нет — токен живёт только в настройках GitHub и Cloudflare.

## Делать нечего: бот не требует обслуживания

Никаких серверов, баз данных и подписок. Если через полгода захочется
что-то поменять — правь `bot/config.py` и коммить, Actions подхватят.
